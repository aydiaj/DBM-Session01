TVET INTERACTIVE CODELAB STUDIO · DB3 / PDB2

Learning sources and reading

The first lesson starts with the course's goals and the students' prior SQL/SSMS knowledge, then introduces ADO.NET through the first Console connection. EF Core is explained as a future alternative, not coded in this session.

Uploaded material used

  1. Database Management training plan (uploaded 3-page PDF, proposed revision, Oct 2026). p. 1: objectives and course purpose. p. 2: Week 1 SQL Server/ADO.NET and Week 2 ORM/EF Core; platform and resource descriptions. p. 3: the rest of the course progression and assessment.
  2. From SQL to EF Core — Introduction & Technology Bridge (instructor slides, 22 pages). Pages 2–7: DB2 recall, roles of SQL/SQL Server/C# and application access. Pages 9–13: connection, command, reader and manual object mapping. Pages 14–18: EF Core motivation and layered architecture. The slides' cover labels TVET Level 1; this website follows the plan's PDB2 Level 2 designation.
  3. Brian Gorman, Practical Entity Framework Core 10, Chapter 1 excerpt, especially "ADO.NET to the Rescue" (book p. 5) and introduction to ORM/Code First (book pp. 7–9). These support the motivating comparison, not an EF coding exercise today.
  4. Jon P. Smith, Entity Framework Core in Action, 2nd ed., Chapter 1 excerpt, especially the relational-to-.NET mapping table (book p. 7) and basic Console example (book p. 9). These help preview the later ORM work.
